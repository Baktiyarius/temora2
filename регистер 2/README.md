# temora

TÉMORA STUDIO — demo

Запуск локально:

1) Установите зависимости:

```powershell
npm install
```

2) Запустите сервер:

```powershell
npm start
```

3) Откройте http://localhost:3000

Функции:
- Регистрация/вход (локально и на сервере)
- Просмотр прайса
- Создание записей (сохраняется в SQLite и localStorage)
- Админка (POST /api/admin/login с паролем temora2025)
